Experiment 2: Student Management System using Git and GitHub
Step 1: Open VS Code and create a project
Open VS Code.

Click File → Open Folder.

Create a folder named student-management.

Open that folder.

Click New File and create index.html.

Step 2: Add the code
Open index.html and paste:

<!DOCTYPE html>
<html>
<head>
    <title>Student Management System</title>
</head>
<body>

    <h2>Student Management System</h2>

    <input type="text" id="name" placeholder="Student Name">
    <input type="text" id="roll" placeholder="Roll Number">
    <input type="text" id="dept" placeholder="Department">

    <button onclick="addStudent()">Add Student</button>

    <table border="1">
        <tr>
            <th>Name</th>
            <th>Roll Number</th>
            <th>Department</th>
        </tr>
        <tbody id="studentList"></tbody>
    </table>

    <script>
        function addStudent() {
            let name = document.getElementById("name").value;
            let roll = document.getElementById("roll").value;
            let dept = document.getElementById("dept").value;

            if (name == "" || roll == "" || dept == "") {
                alert("Fill all fields!");
                return;
            }

            let table = document.getElementById("studentList");
            let row = table.insertRow();

            row.insertCell(0).innerHTML = name;
            row.insertCell(1).innerHTML = roll;
            row.insertCell(2).innerHTML = dept;

            alert("Student Added Successfully!");

            document.getElementById("name").value = "";
            document.getElementById("roll").value = "";
            document.getElementById("dept").value = "";
        }
    </script>

</body>
</html>

Step 3: Run the application
Right-click index.html → Reveal in File Explorer → Double-click index.html.
Step 4: Open VS Code Terminal
Click Terminal → New Terminal.

Execute these commands one by one:
git init
git add .
git commit -m "Initial commit"
git branch -M main


Step 5: Create GitHub repository
1. Open https://github.com
2. Click New Repository.
3. Enter student-management.
4. Click Create Repository.
Step 6: Push project to GitHub
Replace YOUR_USERNAME with your GitHub username.
git remote add origin https://github.com/YOUR_USERNAME/student-management.git
git push -u origin main


Step 7: Update and push changes
After modifying and saving your code:
git add .
git commit -m "Updated student management system"
git push origin main


Step 8: View commit history
git log --oneline


Result: Student Management System successfully developed using VS Code, tracked using Git, and uploaded to GitHub.

Experiment 5: Git Merge Conflict Resolution using README.md
Aim: Create two branches that modify the same line in README.md, merge the branches, resolve the merge conflict, and push the resolved changes to GitHub.
Step 1: Open VS Code
1. Open VS Code.
2. Click File → Open Folder.
3. Create a folder named git-conflict.
4. Open Terminal → New Terminal.
Step 2: Create README.md
Create a file named README.md in VS Code Explorer.

Add this code:
# Student Management System

This project is developed using HTML.


Save the file.
Step 3: Initialize Git
git init
git branch -M main
git add .
git commit -m "Initial commit"


Step 4: Create first branch
git checkout -b branch1


Open README.md and change the second line to:
This project is developed using Java.


Save and commit:
git add README.md
git commit -m "Updated README using Java"


Step 5: Create second branch
git checkout main
git checkout -b branch2


Open README.md and change the same second line to:
This project is developed using Python.


Save and commit:
git add README.md
git commit -m "Updated README using Python"


Step 6: Merge first branch
git checkout main
git merge branch1


Step 7: Merge second branch
git merge branch2


Git will show a CONFLICT because both branches modified the same line.
Step 8: Resolve merge conflict
Open README.md in VS Code.

You will see:
<<<<<<< HEAD
This project is developed using Java.
=======
This project is developed using Python.
>>>>>>> branch2


Replace it with:
# Student Management System

This project is developed using Java and Python.


Save the file.
Step 9: Commit resolved changes
git add README.md
git commit -m "Resolved README merge conflict"


Step 10: Push to GitHub
Create a GitHub repository named git-conflict.
git remote add origin https://github.com/YOUR_USERNAME/git-conflict.git
git push -u origin main
git push origin branch1
git push origin branch2


Step 11: Verify
git status
git log --oneline --graph --all


Result: Successfully created two branches, modified the same line in README.md, generated and resolved a merge conflict, and pushed the resolved changes to GitHub.

Important Git commands
Command	Purpose
git init	Initialize repository
git add index.html	Stage HTML file
git add style.css	Stage CSS file
git add script.js	Stage JavaScript file
git add .	Stage all files
git restore --staged script.js	Unstage a file
git commit -m "message"	Commit changes
git status	Check repository status
git log --oneline	View commit history
